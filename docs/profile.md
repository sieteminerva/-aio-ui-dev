saya kasih latar belakang sedikit ya.. dulu saya adalah seorang designer visual (graphic design, 3d design, product design, packaging design). dan saya memang punya ketertarikan yang kuat dalam membuat/menciptakan sesuatu, dari kecil saat manual ilustrasi tangan sampai jaman computer graphic ketika saya sudah kuliah (2002). sejak kuliah saya punya usaha sambilan dibisnis printing kecil-kecilan, dan design buku tahunan anak sma. saya memulai karier kerja saya sebagai designer cover album music, dan design platinum award untuk music mulai 2005-2006. ketika tahun 2008 saya memenangkan ami award best cover album design indonesia saya memutuskan berhenti dan mencari pengalaman design lain, saya mulai fulltime memasuki dunia advertising khususnya di below the line. dari situ usaha printing saya yang tadinya iseng jadi lebih berkembang, karena projek yang saya kerjakan memberikan order printingnya sekaligus kesaya biar rapi karena kan saya juga yang design. itu berlangsung sampai 2010-2011. setelah itu saya memutuskan untuk berhenti juga dan mulai fulltime membuat workshop sendiri. workshop sedikit lebih luas area kerjanya tidak hanya printing, tapi diaplikasikan ke kemasan. khususnya box-box exclusive seperti kemasan untuk harvest cake & coklat, garuda indonesia, dsb rutin memesan disaya. meskipun orderan BTL dari klien sebelumnya masih masuk juga, plus saya juga merangkap consultan design untuk kantor-kantor baru dari design brand identitynya sampai ke tahap produksi jadi. namun naas usaha ini tidak berlangsung lama mungkin hanya 2 tahun. dikarenakan pekerjaan ini sering kali memperkerjakan sdm rendah kan. dimana service saya menuntut kesempurnaan tapi pekerja2 saya sering kali mengabaikannya. timbul lah kerugian, dan singkat cerita saya tutup workshopnya. dan saat itu saya memikirkan gimana caranya mengautomasi (mendigitalisasi) semuanya. sampai akhirnya setelah itu saya mulai lah iseng-iseng belajar programming (sebelumnya sih dah menghabiskan uang banyak untuk bayar orang tapi kok ga bisa jadi sesuai mau saya jadilah nyebur sendiri). intinya cuma mau buat printing production calculator. tapi ternyata programming itu rumit sekali, dan saya tenggelam didunia programming ini dan malah jadi pekerjaan. sampai akhirnya semua saya buat, printing calculator, parametric dieline generator dgn output svg atau gcode, auto generated cms, sampai frontend frameworks dan cli nya pun saya buat. beserta beberapa mesin diy cnc saya bangun, karena jujur saja saya tidak melupakan dunia packaging begitu saja, prinsip yang saya buat masih terukir jelas dibenak saya. "Produk memang mempunyai harga, tapi kemasan menambah nilainya." dan tagline saya "we learn, we build, we innovate". kamu boleh interview saya lebih lanjut dari background yang saya sampaikan
