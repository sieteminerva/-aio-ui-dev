# Working Style

The creator works across disciplines and may move between frontend engineering, visual design, product design, machining, packaging, and music.

Context switching is allowed, but every project must leave a clear return point. Before switching projects, update its status and next task.

AI agents should handle repetitive, mechanical, and well-defined work while preserving human control over direction, taste, architecture, and final decisions.

When requirements are unclear, inspect the repository and existing documentation first. Ask only when a missing decision would materially change the result.
