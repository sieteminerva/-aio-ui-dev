# Language Convention

## Default

The user may communicate in Indonesian, English, or a mixture of both. The language of the prompt does not automatically determine the language of the implementation.

Unless explicitly requested otherwise:

- Write source code identifiers in English.
- Write comments, JSDoc, and TypeDoc in English.
- Write project documentation in English.
- Write generated content and user-facing project copy in English.
- Keep technical terms and API names in their established English form.

## Explicit Language Requests

When the user explicitly requests Indonesian for a specific artifact, use Indonesian for that artifact only. Do not translate unrelated source code, documentation, or content unless requested.

## Conversation

Reply in the language that best matches the user's latest message. Indonesian conversation may still produce English implementation artifacts by default.
